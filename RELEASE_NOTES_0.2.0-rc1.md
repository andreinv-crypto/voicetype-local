# VoiceType Local 0.2.0-rc1 — public preview

VoiceType Local is an accessibility-first voice typing tool for Windows 10/11.
Put the cursor into almost any text field, press **Right Ctrl**, speak, and press
**Right Ctrl** again. Recognition works locally by default.

This is a **pre-release for testing**, not a signed production release.

## Что улучшено

- Whisper вынесен в отдельный перезапускаемый процесс: зависшую модель можно
  принудительно остановить, есть таймауты и один чистый повтор.
- Микрофон не блокирует интерфейс. Добавлены WASAPI-first, таймауты start/stop,
  abort и circuit breaker для зависшего драйвера.
- Текст автоматически вставляется только в то же самое поле. Если фокус
  изменился или неизвестен, текст остаётся доступным до выхода из программы.
- Для современного Блокнота Windows 11 добавлена проверяемая адресная
  Unicode-вставка без буфера обмена: русский, английский, испанский, переносы и
  emoji больше не зависят от потерь быстрых синтетических нажатий.
- Для остальных UI Automation-текстовых полей обычная вставка теперь проходит
  единым безопасным циклом: проверка поля прямо перед вводом и один атомарный
  `SendInput`. Если Chromium/Electron пересоздаёт поле после полного нативного
  ввода, программа сообщает «текст отправлен» и никогда не повторяет его
  автоматически; голосовое редактирование и Enter без строгого подтверждения
  не выполняются.
- Адресная вставка и голосовое редактирование выполняются с таймаутом вне
  интерфейсного потока; при неопределённом результате автоматического повтора
  нет.
- Добавлена небольшая локальная память: термины, правильные написания, алиасы,
  языки, области и отключённые по умолчанию тематические наборы.
- Есть безопасная локальная постобработка пунктуации и очевидных ошибок.
- Локальные контекстные исправления ограничены текущей фразой и точными
  правилами; скрытая междиктовочная история для корректора не сохраняется.
- Автопробел между последовательными диктовками в том же поле включён по
  умолчанию; его можно явно выключить в настройках текста.
- Опциональные OpenAI/Ollama-режимы выключены по умолчанию. Для текста и аудио
  нужны разные явные согласия; ключ хранится через Windows DPAPI.
- Добавлены доступные настройки и редактор памяти с крупным шрифтом и полной
  клавиатурной навигацией.
- В настройках добавлена **Быстрая проверка**: отдельное собственное поле ведёт
  по четырём голосовым шагам — диктовке, удалению последнего предложения,
  возврату исправления и замене последнего предложения. Сценарий принудительно
  использует локальный Whisper и локальную
  коррекцию; текст и результаты остаются только в RAM, без истории, логов и
  облака. Сводка без транскрипта копируется только явно.
- Реализованы технические логи без аудио, транскриптов и словаря, безопасная
  установка и транзакционный rollback.

## Как попробовать

1. Скачайте `VoiceType-Local-0.2.0-rc1-windows-x64.zip` из Assets.
2. Распакуйте архив целиком в обычную папку.
3. Запустите `VoiceType Local\VoiceType Local.exe`.
4. Поставьте курсор в текстовое поле и используйте правый Ctrl.

Сборка пока не подписана сертификатом, поэтому Windows SmartScreen может показать
предупреждение. Не запускайте файл, полученный не со страницы этого релиза.

## Приватность

По умолчанию аудио, текст и словарь остаются на компьютере. История диктовок не
сохраняется. Облачные режимы включаются только вручную. Экспорт памяти — обычный
незашифрованный JSON, поэтому относитесь к нему как к личному документу.

## Проверка

Быстрая проверка — это smoke основной локальной цепочки. Она сокращает ручной
прогон, но не заменяет выборочную проверку установленной сборки в Notepad,
браузере, мессенджерах и других реальных полях.

- 1 050 автоматических тестов;
- packaged self-test, изолированный UI smoke-test и отдельная Win32 RichEdit
  проверка Unicode/таймаута;
- `pip-audit` на 21 июля 2026 года не обнаружил известных advisory в
  проверенных Python runtime-зависимостях; это не полный security-аудит;
- независимые review-проходы по вставке, командам и корректору завершены без
  открытых blocker/high замечаний;
- тест памяти: 10 000 синтетических терминов занимают около 5,5 МБ.

## Известные ограничения preview

- только Windows 10/11 x64;
- архив около 758 МБ в распакованном виде, поскольку содержит локальную
  многоязычную Whisper-модель;
- цифровой подписи пока нет;
- проверяемая адресная вставка в современный Блокнот пока ограничена документом
  до 65 536 UTF-16-единиц; для более длинного документа применяется безопасный
  отказ без менее надёжного повтора;
- перед массовым распространением нужны дополнительные реальные голосовые
  тесты на разных компьютерах и микрофонах.
- команда «выделить последнее предложение» в этот candidate не входит; она
  оставлена в дорожной карте после стабилизации базовых команд.

Hotfix 21 июля: обычная диктовка снова работает в Codex, Chromium и Electron
полях без UI Automation `TextPattern`. Для них используется один атомарный
`SendInput` с повторной проверкой поля прямо перед вводом; строгие голосовые
правки по-прежнему требуют читаемого текстового поля. Пересозданная Chromium-
цель может обновиться только в момент явного второго нажатия/отпускания клавиши;
после этого любое изменение поля снова блокирует вставку и конечную команду.
