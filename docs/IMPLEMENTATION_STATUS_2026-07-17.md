# VoiceType Local — статус реализации на 17 июля 2026

Этот файл фиксирует фактическое состояние ветки `codex/voice-control-vnext`.
Он нужен для переноса проекта между чатами и компьютерами без восстановления
контекста по истории разговора.

## Что реализовано

- Правый Ctrl и режим `нажал — включил / нажал — выключил` сохранены по
  умолчанию; доступны безопасные альтернативные клавиши и режим удержания.
- Режимы `Диктовка`, `Команды` и `Смешанный`; в смешанном режиме управление
  начинается только с `команда / command / comando`.
- Строгий RU/ES/EN parser без LLM, shell, произвольных путей, URL и командной
  строки.
- Открытие только известных приложений, переключение/состояние окон, прокрутка,
  безопасные клавиши, нажатие UI Automation элемента по имени или номеру.
- Номерной слой и справка команд не забирают фокус; снимки содержат только
  краткоживущие immutable-дескрипторы и очищаются после hide/cancel/TTL/exit.
- Чувствительные кнопки, ссылки, пункты меню, `Space`, `Enter`, удаление и
  закрывающие сочетания требуют отдельного подтверждения.
- Подтверждение одноразовое, действует 45 секунд и связано с исходным окном,
  snapshot, элементом либо foreground-окном для клавиши. Смена target означает
  отказ.
- Cancel/Escape инвалидирует pending и поздний результат через cancellation
  epoch; locks не удерживаются во время медленных UIA-вызовов.
- UIA/SendInput блокируются для terminal/admin/elevated или неизвестного
  foreground; сам elevated VoiceType не получает Control-capability.
- Команды диктовки `новая строка`, `абзац`, `таб`, знаки препинания на RU/ES/EN;
  URL, email, числа и код защищены от преобразований.
- Бережная локальная коррекция, исходный и финальный текст, повторная вставка,
  копирование и очистка текущей сессии. Постоянной истории нет.
- Настройки и DPAPI-ключ сохраняются с rollback: сначала создаются candidate
  providers/hotkey, запись настроек copy-on-write, затем runtime swap. Облачный
  режим нельзя включить без существующего или нового ключа.
- Повреждённый, не-object или слишком большой `settings.json` безопасно даёт
  локальные настройки по умолчанию.
- `uiautomation==2.0.29` закреплён; добавлены import-only packaged self-test,
  PyInstaller metadata/hidden imports и отдельная проверка Control-модулей.

## Что ещё не считается доказанным

Candidate собран и прошёл автоматические проверки, но это ещё не готовый
публичный Windows-релиз. До release нужны:

1. Вручную проверить Notepad, браузер, Проводник и Electron-приложение.
2. Проверить standard/elevated app, UAC secure desktop и запуск самого VoiceType
   без elevation.
3. Проверить смену focus во время длинной вставки, terminal/newline/tab и browser
   omnibox. Диктовка является вводом текста в выбранное пользователем поле;
   запрет shell относится к VoiceType Control, а не к содержимому диктовки.
4. UIA-вызов сторонней библиотеки теоретически может зависнуть. Cancellation
   не использует поздний результат, но жёсткая остановка зависшего COM-call
   потребует отдельного worker process. Это остаётся release-hardening gate.
5. Для публичного бинарного релиза остаются финальная проверка состава dist,
   проверка лицензий/SBOM, антивирусная проверка и в дальнейшем code signing.

Ручные шаги отмечаются только по факту в
[`MANUAL_ACCEPTANCE_CHECKLIST.md`](MANUAL_ACCEPTANCE_CHECKLIST.md).

## Осознанно отложено

- постоянная лента истории и сохранение аудио;
- OCR/vision, мышиная сетка, drag-and-drop и автономный AI-агент;
- обязательные многогигабайтные модели;
- полноценный редактор шаблонов и модельный менеджер;
- окончательная подпись/автообновление и коммерческая упаковка.

Подробный текущий объём находится в
[`CURRENT_IMPLEMENTATION_PLAN.md`](CURRENT_IMPLEMENTATION_PLAN.md), а отложенные
идеи — в [`FUTURE_ROADMAP.md`](FUTURE_ROADMAP.md).
