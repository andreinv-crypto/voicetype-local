# VoiceType Local: обязательный контекстный корректор

Статус: **подтверждён Андреем 21 июля 2026 года; ещё не реализован**.
Это обязательный следующий слой качества после стабилизации основной диктовки
и команд. Функция предназначена для всех пользователей, особенно для людей,
которым трудно вручную исправлять текст.

## Цель

После локального Whisper автоматически исправлять очевидные ошибки
распознавания с учётом смысла текущей фразы и короткого контекста, но не
переписывать мысль пользователя. Примеры наблюдавшихся ошибок:

- `голосового вода` вместо `голосового ввода`;
- `voice tubing` вместо `voice typing`;
- неверная пунктуация, регистр и очевидные соседние повторы.

Корректор работает **до вставки текста**, не требует дополнительного клика и
всегда позволяет вернуть исходный вариант.

Свободное переписывание выделенного текста (`сделай короче`, `переведи`,
`измени стиль`) является отдельным будущим LLM-режимом. Оно не входит в
бережный корректор и не должно запускаться случайной фразой обычной диктовки.

## Безопасный поток

```text
аудио в RAM
  -> локальный Whisper
  -> встроенная пунктуация и нормализация
  -> личный словарь и термины
  -> контекстный корректор
  -> защита чисел / дат / сумм / URL / email / кода
  -> проверка уверенности
  -> вставка исправленного текста
  -> «Вернуть исходный текст» до следующей независимой операции
```

Для контекста разрешено использовать только текущую расшифровку, несколько
последних диктовок текущей RAM-сессии и необязательный профиль приложения.
Читать переписку, документы или экран без отдельного согласия нельзя.
Контекст автоматически очищается по завершении сессии/тайм-ауту и не создаёт
постоянную историю.

## Режимы

1. `Без коррекции` — исходный результат Whisper.
2. `Бережная` — встроенные локальные правила; безопасный режим по умолчанию.
3. `Контекстная AI` — более сильное исправление смысла, добровольно.

Место обработки выбирается отдельно:

- `Встроенно` — без сети и дополнительной модели;
- `Локальная AI` — добровольный компактный пакет с заранее показанным размером;
- `Облачная AI` — только после отдельного согласия и ясного указания, какой
  текст отправляется провайдеру.

Отсутствие сети, модели или ключа никогда не блокирует диктовку: программа
мгновенно возвращается к бережному локальному результату.

## Жёсткие ограничения

- Не менять числа, даты, суммы, телефоны, URL, email, команды, имена файлов и
  фрагменты кода без высокой уверенности и специального правила.
- Не добавлять факты, которых пользователь не произносил.
- Не менять язык и стиль, не делать текст «красивее» без отдельной настройки.
- Не превращать обычную диктовку в команду управления Windows.
- Не сохранять исходный или исправленный текст в постоянную историю по
  умолчанию.
- При сомнении оставлять исходный текст.

## План реализации

### Шаг 1. Стабильная локальная основа

- Выделить единый интерфейс коррекции и защищённые токены.
- Подключить текущую пунктуацию, пробелы, регистр, повторы и личный словарь.
- Хранить `исходный -> исправленный` только в RAM.
- Добавить действие и голосовую команду `вернуть исходный текст`.

### Шаг 2. Контекст без тяжёлой модели

- Передавать Whisper безопасный словарный prompt и короткий контекст сессии.
- Исправлять только подтверждённые высокоуверенные пары и терминологию.
- Добавить RU/EN/ES и смешанные регрессионные примеры.

### Шаг 3. Добровольная AI-коррекция

- Сначала сравнить компактную локальную модель и облачную модель на одном
  обезличенном наборе ошибок.
- Показать пользователю размер, задержку, стоимость и приватность до включения.
- Встроить provider-интерфейс, тайм-аут, отмену и локальный fallback.

### Шаг 4. Приёмка

- A/B-проверка на одинаковых RU/EN/ES и смешанных фразах.
- Нулевая регрессия защищённых токенов и команд.
- Измерение дополнительной задержки и числа полезных/ошибочных исправлений.
- Ручная проверка в Codex, Chrome, Notepad и мессенджере без автоматической
  отправки сообщений.

## Критерий готовности

Функция считается готовой, когда она заметно сокращает ручные исправления,
не меняет смысл и защищённые данные, отключается одной настройкой, работает без
сети в базовом режиме и позволяет одним действием вернуть исходный текст.
