# VoiceType Control — ручная приёмка Windows

Дата подготовки: 17 июля 2026 года; актуализировано 18 июля 2026 года.
Автоматические проверки исходного кода
пройдены, и candidate установлен для локальной проверки. Финальные отметки в
этом списке ставятся только после проверки установленного EXE в реальных
приложениях. Использовать нейтральный тестовый текст; не открывать пароли,
платежи, реальные письма или важные документы.

## 1. Регрессия обычной диктовки

- [ ] После обновления стоят `Правый Ctrl`, `Переключатель`, `Диктовка`.
- [ ] Правый Ctrl начинает запись; следующее нажатие завершает её.
- [ ] Долгое удержание и autorepeat дают одно переключение.
- [ ] Левая клавиша Ctrl, мышь и остальные клавиши ничего не запускают.
- [ ] RU, ES, EN и Auto вставляют нейтральный текст в Notepad.
- [ ] Длинная фраза в Notepad вставляется целиком; прежний сбой `первое слово
      и затем точки` не воспроизводится при нескольких повторных попытках.
- [ ] Смена поля во время обработки не вставляет текст вслепую; итог остаётся
      доступен для копирования/повтора.
- [ ] Escape отменяет запись или обработку и не остаётся подавленным после
      отмены.

## 2. Новый интерфейс, способы запуска и доступность

- [ ] Тёмный интерфейс соответствует подтверждённому варианту №3; открываются
      шесть непустых страниц: `Главная`, `Речь`, `Текст`, `Приватность`,
      `Доступность`, `О программе`.
- [ ] На `Главной` видны три режима: `Обычный`, `Диктовка`, `Управление`;
      выбранный режим сохраняется и действительно меняет маршрутизацию речи.
- [ ] При компактном размере окна нижние элементы `Главной` доступны через
      прокрутку и не обрезаются.
- [ ] Цепочка `услышано → текст → команда → результат` обновляется после
      проверки и не появляется снова после полного перезапуска программы.

- [ ] F8 и Ctrl+F8 работают в `Переключатель`; модификатор сам не запускает
      запись и проходит в активную программу.
- [ ] F8 и Ctrl+F8 работают в `Удерживать`: нажатие начинает, отпускание
      завершает; autorepeat не влияет.
- [ ] Pause доступен только в `Переключатель`; `Pause + Удерживать` отклоняется.
- [ ] Сброс доступности возвращает `Правый Ctrl + Переключатель`, крупный
      высококонтрастный индикатор сверху и звук.
- [ ] Варианты размера, контраста и положения индикатора не забирают фокус.
- [ ] Все шесть страниц и кнопки доступны через Tab/Shift+Tab; Enter сохраняет,
      Escape закрывает без сохранения.

## 3. Команды внутри диктовки

- [ ] `Привет запятая мир точка новая строка дальше` вставляется с запятой,
      точкой и переносом, не нажимая физический Enter.
- [ ] Проверить аналоги `comma/new line` и `coma/nueva línea`.
- [ ] URL, email, дата, сумма и код остаются байт-в-байт.
- [ ] Удаление слов-паразитов выключено по умолчанию и работает только после
      явного включения.
- [ ] Автопробел выключен по умолчанию; после включения срабатывает только для
      двух успешных вставок в том же поле в пределах 30 секунд.
- [ ] В `Обычный` фраза `Тест, нажать Enter` вставляет только `Тест`, затем
      просит подтверждение и лишь после `подтверждаю` нажимает Enter.
- [ ] Аналоги `Test, press Enter` и `Prueba, pulsa Intro` ведут себя так же.
- [ ] `Текст, отправить сообщение`, `Text, send message` и `Texto, enviar
      mensaje` удаляют служебный хвост из текста и требуют подтверждения перед
      отправкой.
- [ ] При отказе, Escape, ошибке вставки или смене поля ожидаемое действие
      Enter/отправки не выполняется.

### Безопасное редактирование последней вставки

Все проверки выполнять на нейтральном тексте в отдельном тестовом поле.

- [ ] В `Обычный` после диктовки `Первое предложение. Второе предложение.`
      команда `команда удали последнее слово` удаляет только слово
      `предложение.` вместе с нужным пробелом; без слова `команда` эта же фраза
      печатается как обычный текст.
- [ ] В `Управление` фраза `delete last sentence` работает без префикса, а в
      `Диктовка` печатается как текст и ничего не удаляет.
- [ ] RU: `команда замени последнее предложение на Всё готово` заменяет только
      последнее предложение последней вставки.
- [ ] EN: `command replace last word with ready` заменяет только последнее
      слово последней вставки.
- [ ] ES: `comando reemplaza la última frase por Todo está listo` заменяет
      только последнюю фразу последней вставки.
- [ ] `команда замени черновик на готовый текст` работает, если `черновик` встречается в
      последней вставке ровно один раз и является целым словом.
- [ ] Если искомая фраза отсутствует или встречается дважды, точная замена
      отклоняется; программа просит уточнить, а текст остаётся без изменений.
- [ ] После одного успешного изменения `команда верни последнее исправление` /
      `command undo last voice edit` / `comando deshaz la última corrección`
      восстанавливает проверенный предыдущий текст только в том же поле.
- [ ] Возврат последнего голосового исправления не запускает общий `Ctrl+Z`:
      соседние ручные изменения и undo-stack приложения не затрагиваются.
- [ ] Перемещение курсора внутрь последней вставки, создание другого выделения
      или ручное изменение текста приводят к отказу без удаления символов.
- [ ] Переключение в другое поле или окно до команды и во время проверки
      приводит к отказу; новое поле не изменяется.
- [ ] Поле пароля и поле без подходящего UI Automation TextPattern отклоняются
      без fallback на слепые Backspace/Delete.
- [ ] `команда удали последнюю диктовку` удаляет только последнюю проверенную
      вставку VoiceType; следующая команда `команда верни последнее исправление`
      один раз восстанавливает её только в том же подтверждённом пустом поле.
- [ ] После принятой попытки возврата полностью удалённой вставки повторная
      команда отклоняется. В другом или непустом поле попытка не вставляет
      старый текст и также не переносит его между полями.
- [ ] После перезапуска программы прежняя вставка не редактируется: текстовая
      транзакция хранится только в RAM текущего процесса.

## 4. VoiceType Control

Для каждого приложения использовать только нейтральные действия:

- [ ] Notepad: открыть, свернуть/развернуть, показать номера, выбрать безопасный
      пункт.
- [ ] Chrome или Edge: переключиться, прокрутить, показать номера, выбрать
      безопасную вкладку/кнопку.
- [ ] Проводник: открыть, переключиться, прокрутить; не удалять и не перемещать
      файлы.
- [ ] Electron-приложение (например VS Code): переключиться, показать номера,
      выбрать безопасную вкладку.
- [ ] В `Диктовка` фраза команды печатается как текст и не выполняется.
- [ ] В `Обычный` команда без `команда/command/comando` печатается как текст,
      кроме точных подтверждаемых действий в самом конце диктовки.
- [ ] Нераспознанная команда в `Управление` не печатается и не выполняется.
- [ ] Произвольный путь, URL, `.exe`, terminal, PowerShell, registry, admin и
      UAC отклоняются.
- [ ] После `покажи номера` смена окна убирает слой примерно за 0,5–1 секунду;
      старый номер не действует.

## 5. Подтверждения и защита от смены контекста

- [ ] `Enter`, `Space`, Delete/Backspace, чувствительные сочетания и элементы
      `Send/Share/Pay/Delete/Confirm` не выполняются без подтверждения.
- [ ] Подтверждение относится только к исходной команде, исходному окну и
      исходному UIA-снимку; после переключения окна действие отклоняется.
- [ ] Любая новая фраза, обычная диктовка, Escape или смена режима отменяет
      старое ожидание подтверждения.
- [ ] Ожидание автоматически исчезает через 45 секунд; после этого
      `подтверждаю` ничего не выполняет.
- [ ] VoiceType, запущенный от администратора, блокирует Windows-control; он не
      пытается обходить UAC/secure desktop.

## 6. Приватность и завершение

- [ ] `Скопировать исходный`, `Скопировать итог` и `Очистить сессию` работают;
      после очистки в уже открытых настройках не остаётся старого результата и
      кнопки повтора/копии/очистки отключены.
- [ ] После скрытия номеров/отмены в executor не остаётся доступного snapshot.
- [ ] Технический лог содержит только event/operation/code/backend/count/time;
      в нём нет произнесённых фраз, UIA Name, заголовков, путей и документов.
- [ ] После выхода raw/local/final text, pending confirmation и UIA snapshot
      очищены; постоянной ленты истории и сохранённого аудио нет.
