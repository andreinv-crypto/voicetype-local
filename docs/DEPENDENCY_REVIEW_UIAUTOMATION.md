# Dependency review: uiautomation 2.0.29

Дата проверки: 17 июля 2026 года.
Назначение: доступ к Microsoft UI Automation для VoiceType Control.

## Решение

Закреплена версия `uiautomation==2.0.29`.

- Официальный PyPI указывает версию 2.0.29, выпуск 5 августа 2025 года,
  лицензию Apache-2.0 и единственную runtime-зависимость `comtypes>=1.2.1`.
- В VoiceType уже закреплён `comtypes==1.4.16`; новая транзитивная зависимость
  не добавляется.
- Wheel `uiautomation-2.0.29-py3-none-any.whl` имеет размер около 199 КБ.
- Проверенный SHA-256 wheel:
  `5dd51c9e77e70470142a13d903be67f256c445e7cf20b47ada0ece2bdaff9f32`.
- Хэш совпал со значением, опубликованным PyPI.
- Поиск по распакованному wheel не обнаружил сетевого клиента, телеметрии или
  аналитики. Найденный `subprocess.Popen('notepad.exe')` находится только в
  демонстрационном CLI-блоке исходного пакета и не вызывается VoiceType.
- VoiceType импортирует пакет только внутри optional factory и использует
  ограниченные методы UI Automation. Скрипты пакета не запускаются.

Официальные источники:

- <https://pypi.org/project/uiautomation/>
- <https://github.com/yinkaisheng/Python-UIAutomation-for-Windows>
- <https://learn.microsoft.com/windows/win32/winauto/uiauto-uiautomationoverview>

## Ограничения безопасности VoiceType

- Приложение не запускается от администратора и не обходит UAC.
- Elevated/terminal/admin-окна блокируются вторым Win32 policy gate.
- UIA читает только имя, роль, доступность, runtime id и геометрию доступных
  элементов; значения полей и содержимое документов не читаются.
- Живые COM-объекты не переносятся между потоками: при выполнении элемент
  находится повторно и сверяется с текущим snapshot.
- Каждая UIA-операция в worker thread использует
  `UIAutomationInitializerInThread`, как требует документация пакета.
- Чувствительные и разрушительные элементы требуют отдельного подтверждения.
- В журнал не попадают имена элементов, текст команды или содержимое окна.

## Обновление

Не обновлять пакет автоматически. Новая версия принимается только после
повторной проверки лицензии, зависимостей, hash, diff/API и тестов номерного
слоя. Yanked-релизы 2.0.21–2.0.26 не использовать.
