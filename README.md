# VoiceType Local

Простой локальный голосовой ввод для Windows 10/11:

1. Поставьте курсор в любое текстовое поле.
2. Один раз нажмите **правый Ctrl** — начнётся запись.
3. Говорите.
4. Ещё раз нажмите **правый Ctrl** — запись остановится, речь распознается и текст появится в том же активном окне.

**Правый Ctrl полностью выделен для VoiceType.** Все остальные клавиши и клики
мыши не влияют на включение и выключение записи. Они по-прежнему работают в
активном окне и могут переместить курсор. Для обычных сочетаний `Ctrl+C`,
`Ctrl+V` и других используйте левый Ctrl.

## Что уже есть

- полностью локальное распознавание через multilingual Whisper `small`;
- русский, испанский и английский, автоопределение или ручной выбор в трее;
- глобальный переключатель на правом Ctrl;
- запись с системного микрофона;
- Unicode-вставка без изменения буфера обмена;
- маленький индикатор, который не забирает фокус;
- системный tray, отмена и повторное копирование последнего текста;
- аудио обрабатывается только в оперативной памяти, временные WAV не создаются, история расшифровок не ведётся.

Если во время распознавания вы переключили окно, текст не теряется. Поставьте
курсор в нужное поле и ещё раз нажмите **правый Ctrl** — сохранённый текст
вставится туда.

## Сборка на этом компьютере

```powershell
.\setup.ps1
.\build.ps1
```

Готовая программа будет здесь:

```text
dist\VoiceType Local\VoiceType Local.exe
```

Модель входит в папку сборки, поэтому после сборки интернет и Python не нужны.

## Настройки

При первом сохранении создаётся только файл настроек:

```text
%LOCALAPPDATA%\VoiceTypeLocal\settings.json
```

Расшифровки и записи там не сохраняются. Язык можно менять прямо через значок VoiceType Local в системном трее.

## Известные ограничения MVP

- Вставка в окно, запущенное от администратора, блокируется Windows, если VoiceType Local работает без повышенных прав.
- Некоторые защищённые поля и терминалы могут не принимать Unicode-ввод. Последний текст остаётся в памяти приложения и его можно скопировать через меню трея.
- Модель `small` даёт локальность и нулевую стоимость, но не выполняет AI-переписывание и глубокое удаление слов-паразитов как Wispr Flow.
- Автозапуск Windows пока не включается автоматически.
- Одна запись ограничена пятью минутами, чтобы не перегружать память компьютера.

## Приватность

Приложение не читает экран и соседний текст, не отправляет аудио в интернет, не хранит историю и не требует API-ключей. Сеть нужна только один раз при подготовке модели разработчиком.
