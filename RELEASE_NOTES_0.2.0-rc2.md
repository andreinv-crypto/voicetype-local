# VoiceType Local 0.2.0-rc2 — stabilization candidate

Это тестовый кандидат, опубликованный параллельно с предыдущей версией. Он не
заменяет `v0.2.0-rc1` и не считается стабильным релизом.

## Два независимых пакета

- **Candidate** — новая сборка с VoiceType Control, безопасным редактированием,
  улучшенной вставкой и локальным контекстным корректором.
- **Known-working rollback** — точная копия предыдущей локальной сборки,
  сохранённая на случай, если candidate окажется менее стабильным. Это
  бинарный снимок для отката; он не соответствует исходникам тега rc2.

Оба архива portable: распакуйте архив целиком и запускайте
`VoiceType Local\VoiceType Local.exe`. Одновременно две версии запускать не
следует.

## Проверка candidate

- 1 050 автоматических тестов;
- `compileall`, packaging preflight, packaged self-test и UI smoke-test;
- Microsoft Defender custom scan: угроз не найдено;
- живая диктовка в Codex прошла без красной ошибки, pending-состояния и повтора;
- SHA-256 EXE candidate:
  `90CC8AB54AC7D28344CB17452E5A61BD2C91D53D7CBE99289CC0C85AE1D87069`;
- SHA-256 EXE known-working rollback:
  `0BAAB999CC11C1937E136AD0264ACDEAE1D87A514E4B09CC547AF4D597ED4CB0`.

## Важно

- Это неподписанные тестовые сборки для Windows 10/11 x64; SmartScreen может
  показать предупреждение.
- По умолчанию распознавание и коррекция локальные, история диктовок не
  сохраняется.
- Голосовые команды и редактирование ещё проходят реальную приёмку в разных
  приложениях.
- Следующий приоритет — очевидные ошибки распознавания обычного текста. Уже
  зафиксирован пример `подтверждаю` → `повторяю`; похожая фраза не будет
  автоматически считаться системным подтверждением.
